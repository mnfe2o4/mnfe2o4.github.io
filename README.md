# 我的个人作品集网站

这是我的 GitHub Pages 个人作品集网站，用来记录网页搭建学习、课程学习笔记和游戏数值分析文章。

## 网站地址

https://mnfe2o4.github.io

## 当前内容

目前网站包含：

- 首页
- 关于页
- 文章页
- 联系方式
- GitHub Pages 在线发布
- 旅行手记：2023—2025 年 27 次旅行的地图行程、精选照片和原文游记

## 当前技术栈

这个网站目前使用：

- HTML：负责网页内容和结构
- CSS：负责网页样式
- Markdown：用于整理学习笔记和项目说明
- MathJax：用于在网页中显示 LaTeX 公式
- GitHub Pages：用于发布网站
- Leaflet：用于旅行地图，地图库保存在本地，底图使用 OpenStreetMap

## 旅行栏目

入口为 `travel/index.html`。已整理 27 次旅行、589 张图片（含 30 张视频选帧）和 17 篇游记，录入 39 段已知航班。支持按地区、日期和地点查看旅行，地图照片缩略图可打开大图；公共交通按公开线形或途经站点展示，推定接续注明示意，无法确认的班次保留为空。2026 年及以后的旅行暂未纳入。维护方式见 [旅行栏目说明](travel/README.md)。
