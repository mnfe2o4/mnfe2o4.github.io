# 旅行手记维护

旅行栏目使用静态 HTML、CSS、JavaScript，适用于现有 GitHub Pages。现已整理 2023—2025 年 27 次旅行、589 张展示图片（其中 30 张为视频选帧）、17 篇游记和 39 段已知航班。

内容覆盖国内、日本、新加坡、加拿大、美国和德国。黄石公园和温哥华原有 64 张照片与原文保持原样；黄石另增加 3 张视频选帧。Camera 中的重庆成都、厦门、杭州苏州和美国短途到访也已整理。洛杉矶多次到访合并展示，机场、中转及返程活动纳入对应旅行。2026 年及以后尚未纳入。

## 编辑与生成

公开内容的源文件是 `travel/data/trips.json`，修改后在仓库根目录运行：

```powershell
python -X utf8 tools/build_travel.py
```

此命令使用 Python 标准库，生成旅行首页、全部旅行详情和浏览器数据 `travel/data/trips.js`。无需 npm 或额外安装包。不要只修改生成的 HTML 后又重新生成，否则会覆盖手工修改。生成后运行数据、文件链接与页面锚点检查：

```powershell
python -X utf8 tools/check_travel_data.py
```

本地浏览可以从仓库根目录运行：

```powershell
python tools/preview_site.py
```

这会启动仅本机可访问的 HTTP 服务并打开旅行首页；控制台会显示实际地址，按 Ctrl+C 停止。也可以加 `--no-open` 只启动服务。

直接双击 HTML 时使用本地 Natural Earth 地理简图，不向 OSM 发起缺少 HTTP 来源的请求。HTTP/HTTPS 访问时可以使用在线街道底图，加载失败则回退到简图；右上角可手动切换。低缩放级别使用世界简图，放大后使用对应的北美西部、美国东部、东亚、欧洲或夏威夷区域数据。简图呈现陆地、海岸、湖泊与河流，不包含详细街道。无需先上线才能预览。

## 页面布局

保留首页的双图封面、详情页的大图封面、大小图混排相册，以及相册之后的双栏游记。标题只含目的地；正文不使用首字放大。

地图右侧只有一个完整的“往返交通”折叠表，日期筛选不拆分此表。每日记录整体折叠在地图之后，原有每日照片预览仍可展开查看。地图保留底图切换、全程/局部视角、日期筛选、地点定位与相册联动。

“照片位置”开关默认开启，缩放级别达到 10 后显示 96×72 像素缩略图。邻近照片按屏幕距离合并为带数量的缩略图，点击可在弹窗中选择照片，再进入原有大图查看器；单张直接打开大图。缩略图随日期和地点筛选。首页足迹标签也会随缩放聚合，弹窗列出对应旅行入口。

## 数据结构

- `trips`：标题、日期、说明、游记原文及每次旅行的展示内容。
- `days`：当地日期、标题、顺序排列的停留点 ID、交通方式和沿途记录。
- `transfers`：往返接驳、航班及中转。已知航班可带 `departureTime`、`arrivalTime`、`arrivalDate`，时刻为当地时间；跨日抵达保留抵达日期。无法确认的交通方式和班次为空。
- `stops`：公共地点、显示名称和概略坐标，格式为 `[纬度, 经度]`。它们是地点标记，不是每张照片的原始拍摄坐标。无法确定地点时，`coordinates` 为 `null`，仍可查看关联照片，但不生成猜测的地图标记。
- `routes`：分日期、交通方式和状态的线段。坐标同为 `[纬度, 经度]`，与 GeoJSON 的顺序不同。`transit-alignment` 表示按线路或站点重建；`geometryKind` 区分 `track-shape` 与 `station-chain`；`inferred` 标记推定接续，弹窗会显示局限。`taxi`、`charter`、`coach` 分别为打车、包车、团体巴士，`car` 专指自驾。
- `photos`：唯一 ID、地点 ID、当地日期/时间、文字说明、原始宽高及两种网页图片的相对路径。
- `photos.mapCoordinates`：精选照片用于地图显示的概略位置；照片定位取到小数点后三位，缺少定位时仅关联已知公共景点。无法定位的途中照片不放置标记。
- `photos.mapLocationType`：`area` 为照片拍摄区域，`place` 为公共景点范围；后者会在缩略图提示中标明。
- `photos.locationLabel`：途中照片的地点说明，例如“返程机上”；关联的机场节点不表示该照片恰在机场拍摄。
- `photos.videoFrame`：视频选帧标志；网站只包含选中的静态图片，不包含原视频或私有来源路径。
- `essay` / `essays`：单篇或多篇原文段落。页面只去除用于分段的零宽字符，不修改原文措辞。没有原文的旅行不生成虚构游记。
- `overviewCoordinates`、`mapFocus`：首页足迹位置与详情局部视角；`offlineRegion` 指定区域简图。跨日期变更线的旅行可用 `mapLongitudeOrigin` 调整地图经度，原始坐标仍为标准经度。
- `archive`：尚未制作详情的目录，目前为空。2026 年延期目录只保留在私有工作区，不计入公开统计。
- `scopeEnd`：内容截止日期，目前为 `2025-12-31`。

更换照片时保留原始照片于网站仓库之外，导出小图和大图至 `images/<旅行 ID>/`，移除 EXIF，并更新照片记录。图片没有精确定位时，将它关联到已核实的景点，不补造拍摄坐标。人像保持待选；住宿、私人地址和完整照片定位索引不进入公开数据。

## 路线信息

黄石的道路形状根据停留点重建，仅作历史行程展示，并非连续 GPS 轨迹。页面读取保存的线路，浏览时不向 OSRM 查询坐标。

温哥华已确认：吊桥去程为常规公交；去北岸乘公交，返回市中心乘 SeaBus；10 月 19 日下午租自行车环骑史丹利公园。未记录的公交线号保留为空，公交接续及骑行路线均明确显示为示意。不要根据当前公交规划结果补写成当时实际乘坐的班次。

温哥华去程为 AS1093（LAX—SEA）、AS2100（SEA—YVR），返程为 AS2030（YVR—SEA）、AS1224（SEA—LAX）。洛杉矶联合车站与 LAX 往返均为 FlyAway，Riverside 接驳使用 Metrolink。10 月 21 日 LAX 周边观机属于本次旅行，不因已经离开温哥华而省略。

夏威夷 2025 年 11 月 28 日先到菠萝园再去北岸，为自驾；钻石山和恐龙湾往返为 Uber，其余岛内接续为公共交通。HA804 于 12 月 1 日晚出发，12 月 2 日清晨抵达 LAX。

其他旅行只记录素材能支持的交通方式与顺序。新增加的机场连线是航班连接示意，铁路、公交及一般接续线不代表连续轨迹；未知方式不补写为自驾或公共交通。伊豆横滨已确定为 2025 年 6 月 21—27 日，圣迭戈当地行程为 2025 年 9 月 22—24 日。

2026-11-22 已根据补充信息录入列车号、打车与团车接续，修正本栖湖、拙政园、北京牛街、千岛湖站及 BUR 北站等地点。日本铁路采用国土交通省 2024 轨道数据，美国部分线路采用运营方公开线形；其他线路按途经站点与可行走向还原。当前交通数据用于核对地理走向，不用来猜写历史具体车次。路线数据来源及必要声明见 [地图与线路资料](map-sources.html)。

旅行识别以 Riverside（美国）和上海（国内）为长期据点，其他地点均可作为候选；据点内的出发/返程接驳也可关联旅行。候选识别不等于自动公开，不依据 GPS 异常点虚构到访。

地图底图失败时，地点和线段仍可显示；地图库无法加载时，文字、日期筛选、相册和游记仍可使用；关闭 JavaScript 后仍有静态行程、照片和正文。

## 地图资源与许可

- 地图库：Leaflet 1.9.4，BSD-2-Clause，许可证位于 `vendor/leaflet/LICENSE`。
- 地图数据及道路形状来源：OpenStreetMap contributors，地图中保留署名。
- 底图地址在 JSON 的 `map.tileUrl` 配置。不要预下载或批量抓取 OSM 地图瓦片；浏览器按需加载并遵循服务端缓存头。
- 离线简图为 Natural Earth 公有领域矢量数据，保存于 `data/offline-*.json` 与对应浏览器脚本；它不是缓存的 OSM 瓦片。来源：[Natural Earth 数据与许可](https://www.naturalearthdata.com/about/terms-of-use/)。
- 新增机场坐标取自 [OurAirports 开放数据](https://ourairports.com/data/)，仅将所需公共机场坐标写入展示数据；航班号与时刻来自提供的行程记录。
- 自动化浏览器检查应拦截 OSM 请求并使用本地简图，不反复缩放抓取公共瓦片。在线底图以正常人工交互预览核实。
- 使用规则：[OSM Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/)。
- 公共交通线形与站点资料：国土交通省、Metrolink、LA Metro、Amtrak、SFMTA、BART、Sound Transit、King County Metro、Washington State Ferries、TheBus、MVV、DB 等，完整链接见 [线路资料页](map-sources.html)。SFMTA 衍生数据声明与[原许可证](data/licenses/SFMTA_Transit_Data_License_Agreement.txt)随站点保存；本网站与交通运营方无隶属关系。
- 道路服务说明：[OSRM Demo Server](https://github.com/Project-OSRM/osrm-backend/wiki/Demo-server)。

上线前以本地确认的精选图片和公开数据为准，不复制其他工作区内的原图、精确 GPS 证据文件、票据或照片候选联系表。
